# Out-Anthropic

## 带走自己的资料，保有更换 AI 的自由

**V1.0 · 2026 年 11 月 14 日 · AndyAwake / 星觉科技**

你正在用 Claude，或者过去在里面积累过聊天、项目和文件：这份轻量教程帮助你逐项备份资料，把正在做的工作接到另一种工具上。

不需要先写代码、安装扩展或开发转换工具。从一个项目开始，拿回资料、整理交接、恢复一次真实工作。

## 为什么要做

好用的模型值得学习，但自己的知识、作品和业务不能只存在于一家公司的界面里。准入政策、产品功能、账号状态和供应商经营都可能变化。今天受影响的是部分用户，拥有备份和迁移能力则是每个人、每家企业都需要的准备。

这不是要求你立即停止使用 Claude。你可以继续选择合适的工具，同时把任务方法、提示词、验收标准和成品留在自己掌握中。[项目立场与背景](https://github.com/AndyAwake/Anti-Anthropic/blob/main/POSITION.md)

## 按顺序做完这七步

1. 申请官方导出，下载并保留原件。
2. 盘点聊天、记忆、项目说明、原文件、成品和工作流程。
3. 单独保存记忆，补充自己的工作交接卡。
4. 手工整理最重要的一个项目，暂时不用处理全部历史。
5. 补齐原来上传的文件、生成成品和本地项目。
6. 在国内可用的工具中重做一项真实工作。
7. 从独立副本恢复，记录缺项，再建立定期备份。
